# PDF Note Editor 📝

A lightweight, zero-install web application designed for adding notes, annotations, and filling out forms on PDF documents.

## 🚀 How to Run (Dead Simple)

### For You and Your Wife:
1. **Option A (Zero-Install Single File):**
   - Just double-click **`pdf-notes-editor.html`**!
   - Opens immediately in your default web browser (Chrome, Microsoft Edge, Firefox, Safari).
   - **Zero setup**: No command lines, no Node.js, and no internet connection required.

2. **Option B (One-Click Launcher):**
   - Double-click **`start.bat`**.

---

## 🎁 How to Share With Your Wife
- Simply email or copy the single file **`pdf-notes-editor.html`** (approx 2MB) to her computer.
- She can double-click it to start annotating PDFs immediately!

---

## ✨ Features

- **🔤 Direct Text Notes:** Click anywhere on the page to insert custom text boxes. Adjust font size (10pt–28pt), colors, and background fills (White / Sticky Yellow / Transparent). Drag to reposition notes anywhere on the page. Includes a quick corner **"✕"** button to delete notes.
- **📌 Interactive Sticky Notes:** Drop a sticky pin anywhere on a page. Clicking opens a color-themed comment card (Yellow, Green, Blue, Pink, Orange) with author tags and timestamps. Clicking any existing pin immediately opens that note.
- **📋 Fillable PDF Form Support:** Automatically detects interactive PDF form fields (text inputs, checkboxes, and dropdowns). Fill out forms directly in the browser and save the filled values permanently into the PDF.
- **📋 "All Notes" Sidebar:** Consolidated list of all notes and comments across every page. Clicking any note instantly jumps to that page.
- **🖍️ Highlighter:** Highlight text in translucent fluorescent yellow, green, cyan, or pink.
- **✏️ Freehand Pen:** Smooth sketching, circling paragraphs, margin notes, and signatures.
- **🧹 Eraser:** Delete annotations with a single click.
- **↩️ Undo / Redo:** Full `Ctrl+Z` and `Ctrl+Y` history stack.
- **🔍 Zoom & Navigation:** Zoom in/out, fit to width, high-resolution page thumbnails, and keyboard arrow navigation.
- **💾 Real PDF Export:** Click "Download PDF" to save a standard PDF with all text, sticky notes, highlights, drawings, and filled form data permanently baked in.
- **⚡ Interactive Sample PDF Included:** Click "Sample PDF" in the top bar to test notes, sticky pins, highlights, and fill out the interactive sign-off form on Page 2!
